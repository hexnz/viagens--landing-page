BesTrip - Landing Page de Viagens

Projeto simples de uma página web para apresentar pacotes de viagem pela Europa.

A página contém:
- Banner principal com imagem de destino turístico
- Menu de navegação interna
- Seção sobre a empresa
- Cards com pacotes de viagem
- Comentários de clientes fictícios
- Rodapé com informações do projeto

Pacotes disponíveis:
- Great Experience
- Premium Experience
- Unique Experience

Tecnologias utilizadas:
- HTML5
- CSS3

Como executar o projeto:
Faça o pull do repositorio e abra o arquivo index.html em qualquer navegador.

Arquivos do projeto:
- index.html
- style.css
- pasta assets com imagens
